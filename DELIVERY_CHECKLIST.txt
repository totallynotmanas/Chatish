❓ FREQUENTLY ASKED QUESTIONS

Q: Do I need Go installed to run the system?
A: No! Use chatish.exe directly. Compiled binary is provided (9.1 MB).

Q: How do I get the OTP?
A: Server prints it to console when you attempt login. Copy the 6-digit number.

Q: Can I use the same OTP twice?
A: No. Each OTP is one-time use. Failed login generates a new OTP.

Q: Why can't Charlie access VIP room?
A: Charlie has "Guest" role. VIP requires "Member" or "Admin" role.

Q: Is my data encrypted?
A: Yes. All messages use AES-256-GCM encryption. Unencrypted data never transmitted.

Q: What happens if I modify a message in transit?
A: HMAC-SHA256 signature detects tampering. Server rejects modified messages.

Q: Can I run web and CLI clients simultaneously?
A: Yes. Both connect to same server. Messages visible in all clients.

Q: What if the server crashes?
A: Clients disconnect gracefully. Restart server and reconnect.

Q: Can I add more users?
A: Yes. Modify server.go users map at startup (for demo purposes).

Q: Is this production-ready?
A: Development/Educational implementation. For production: use TLS, secure OTP delivery, persistent user store.
